
# [제안서] Target-Date 기반 절세형 자산 관리 및 리밸런싱 솔루션

## 1. 프로젝트 개요 (Executive Summary)
본 프로젝트는 사회초년생(특히 98년생 타겟)이 5년 내 결혼 및 자택 구매라는 명확한 재무 목표를 달성할 수 있도록 돕는 **지능형 자산 관리 자동화 툴**입니다. 사용자의 생애 주기(Target Date)에 따른 위험 자산 비중 조절(Glide Path)과 한국 특유의 절세 계좌(ISA, 연금저축) 최적화 로직을 결합한 것이 핵심입니다.

## 2. 사용자 페르소나 및 핵심 제약 조건

- **사용자:** 20대 후반(98년생), 월 실수령액 350만 원 내외, 부채 없음.
- **투자 성향:** 손실 감수 폭 5% 내외 (안정 지향적 성장 추구).
- **목표:** 5년 내 주택 구입 자금(시드머니) 확보.
- **핵심 지표:**
  - **PIR(연소득 대비 주택가격) 6배** 기준의 목표 설정.
  - **자기자본 비율(LTV) 60%** 확보를 위한 저축 경로 설계.

> **페르소나 확장 노트:** '98년생'은 타겟 마케팅을 위한 페르소나일 뿐, 실제 시장은 **'목적 자금이 뚜렷한 모든 사회초년생'**으로 정의합니다.

## 3. 시장 규모 (TAM / SAM / SOM)

| 구분 | 규모 | 정의 |
|------|------|------|
| **TAM** (전체 시장) | 약 600만 명 | 국내 2030 세대 경제활동 인구 |
| **SAM** (유효 시장) | 약 200~300만 명 | 그 중 ISA 및 연금저축 계좌 보유자 |
| **SOM** (수익 목표) | 약 50~100만 명 | 소득 수준과 관계없이 **명확한 재무 목표(주택·결혼·자산 형성)** 를 가진 Goal-Oriented 투자자 |

**SOM 재정의 근거: 고소득자가 아닌 '목표 지향적 일반 투자자'를 타겟으로 삼는 이유**

- **고소득자는 이미 해결책이 있다:** PB(Private Banking) 서비스나 자산관리사를 이용하고 있을 확률이 높아 서비스 침투력이 낮습니다.
- **일반 소득자의 Pain Point가 더 강하다:** 월 350만 원 이하의 실수령액을 받는 유저일수록 "푼돈을 굴려 목돈을 만드는 과정"에서 ISA 한도 계산, 세금 처리, 리밸런싱 시점 판단 등의 고통이 가장 큽니다.
- **데이터 가치:** 수십만 명의 일반 투자자 리밸런싱 패턴 데이터는 그 자체로 고가치 금융 인사이트 자산이 됩니다.
- **장기 Lock-in:** 20대에 본 서비스로 자산을 형성한 유저는 30~40대에도 이탈하지 않는 강력한 고객 생애 가치(LTV)를 만들어 냅니다.

**수익화 전환 모델 (Freemium):** 무료로 시작하여 사용자 자산이 일정 규모(예: 5,000만 원)에 도달하면 자동으로 프리미엄 기능으로 전환 유도. 소액 유저 다수를 모아 공동 구매형 ETF 적립 등 거래 비용 절감 플랫폼으로도 확장 가능합니다.

## 4. 수익 모델 (Revenue Model)

초기 과금 없이 **B2B2C 파이프라인 전략**으로 신뢰를 먼저 확보하고 단계적으로 수익화합니다.

### Phase 1~2: 증권사 제휴 리베이트 (Referral Fee)
- 리밸런싱 신호에 따른 매수 실행 시, 제휴 증권사 계좌 경유를 유도하고 거래 수수료의 일부를 리베이트 수취.
- 사용자에게는 무료로 제공되므로 진입 장벽이 낮음.

### Phase 2~3: 프리미엄 구독 (SaaS)
- **유료 기능:** '5% 멘탈 가드' 손실 경보 알림, 세무사 자동 상담 연계, 세금 절감액 리포트 등.
- 예상 구독료: 월 9,900원 ~ 19,900원.

### Phase 3+: AUM 수수료 (투자 일임)
- 장기적으로 금융 투자 일임업 인가 취득 후 관리 자산 규모에 비례한 수수료(0.1~0.3%) 징수.

## 5. 경쟁자 분석 및 차별화

| 서비스 | 특징 | 한계 |
|--------|------|------|
| 핀트(Fint), 에임(AIM) | 일반 계좌 중심 자동 매매 | ISA/연금저축 복잡한 세제 처리 미흡 |
| 토스, 카카오페이 | 자산 조회/관리 위주 | D-Day 기반 구체적 행동 지침 부재 |
| 대형 증권사 앱 | 자체 리밸런싱 기능 탑재 중 | 특정 계좌군 연계 최적화 없음 |

**우리의 포지션:**
- 기존 로보어드바이저는 '무지성 일임'이지만, 본 서비스는 **사용자의 직접 통제** 하에 ISA/연금저축 한도와 세제 혜택을 자동 계산해주는 **'절세 특화 계산기'** 로 시작합니다.
- 토스/카카오가 없는 **'D-Day Glide Path'** — 목표 시점까지 남은 기간에 따라 위험 자산 비중을 자동으로 낮추는 구체적 행동 지침을 제공합니다.

## 6. 핵심 비즈니스 모델 및 기능 (Core Features)

### A. Target-Date Glide Path (생애주기 기반 비중 조절)
- **비즈니스 로직:** 목표 시점(D-5년)이 가까워질수록 주식 등 위험 자산의 비중을 기계적으로 하향 조정.
- **리밸런싱 트리거:**
  - **시간 기반:** 매년 또는 분기별 비중 하향.
  - **변동성 기반:** 전체 포트폴리오 손실이 5%에 근접할 경우 안전자산 비중 즉시 확대.

### B. Tax-Efficient Optimizer (절세 계좌 최적화)
- **비즈니스 로직:** 리밸런싱 시 발생하는 매수/매도 신호를 계좌 성격에 따라 차등 배분.
- **계좌 우선순위:**
  - **매수:** ISA(비과세/분리과세) > 연금저축(세액공제) > 일반 계좌.
  - **매도:** 일반 계좌 > ISA > 연금저축(장기보유 권장).

### C. LTV 기반 저축 가이드
- **비즈니스 로직:** 목표 주택 가격의 60%를 자기자본으로 확보하기 위해 필요한 월별 최소 투자액 산출.

### D. MDD 5% 제어 알고리즘 (신뢰도 핵심 지표)
- **비즈니스 로직:** 단순 주식 투자가 아닌, **정적 자산 배분(Static Allocation)** + **변동성 타겟팅(Volatility Targeting)** 을 결합하여 전체 자산의 낙폭을 5% 이내로 제어.
- **운용 원칙:** 레버리지 미사용, 주식 비중을 보수적으로 설계(채권·현금 비중 우선).
- **신뢰도 근거:** 과거 데이터 기반 백테스팅 결과를 서비스 내 공개하여 알고리즘의 유효성을 사용자에게 직접 검증 가능하게 함.

## 7. 규제 리스크 대응 전략

### 핵심 전략: '투자 자문'이 아닌 '정보 제공 및 계산기'로 포지셔닝

| 단계 | 규제 대응 방식 |
|------|--------------|
| **Phase 1~2** | 특정 종목 추천 없이, 사용자가 직접 설정한 ETF의 비중 계산 결과만 제공하는 **'유틸리티 툴'** 로 운영 (비인허가 영역). |
| **Phase 3** | 직접 주문 체결 대신 **'증권사 앱으로 이동(Deep-link)'** 기능만 제공하여 법적 실행 책임을 증권사에 귀속. |
| **Phase 3+** | 금융위원회 **혁신금융서비스(샌드박스)** 신청 또는 자문업 라이선스 보유 기관과 협업하여 인가 단계 확보. |

## 8. 시스템 설계 요구사항 (Technical Specifications)

### A. 데이터 모델링 (Data Schema)
- **Account:** 계좌 유형(ISA, 연금, 파킹), 현재 잔고, 입금 한도.
- **Asset:** 종목명(ETF), 자산군(주식/채권/현금), 현재가, 보유 수량.
- **Goal:** 목표 금액, 목표 날짜, 허용 MDD(최대 낙폭).

### B. 핵심 알고리즘 (Algorithm)
1. **Rebalancing Engine:** `(Target_Weight - Current_Weight)`를 계산하여 매매 필요 금액 산출.
2. **Tax-Order Engine:** 매매 신호를 세금 혜택이 큰 계좌 순서로 할당하는 최적화 로직.
3. **Safety-Net Logic:** 실시간 손실률이 5% 초과 시 '안전 모드' 가동(현금 비중 강제 확대).
4. **Volatility Targeting Engine:** 자산군별 변동성을 측정하여 목표 변동성(σ=5%) 이내로 비중 조절.

## 10. 팀 (Founding Team)

**솔로 파운더 / 풀스택 개발자**

- **왜 이 문제를 푸는가:** 창업자 본인이 98년생, 월 실수령액 350만 원으로 5년 내 주택 구입을 목표로 하는 **이 서비스의 첫 번째 유저**입니다. 직접 ISA·연금저축 계좌를 운용하며 느낀 불편함(복잡한 세제, 목표 기반 리밸런싱 부재)이 이 프로젝트의 출발점입니다.
- **'Skin in the Game':** 본인의 실제 자산 현황과 포트폴리오를 서비스에 적용하여 공개하는 Build in Public 방식으로 제품의 신뢰도를 직접 증명합니다.
- **리스크:** 단일 창업자이므로 개발·기획·마케팅을 병행해야 합니다. Phase 2 이후 도메인 전문가(금융/세무) 협업자 영입을 계획 중입니다.

## 11. 단계별 개발 로드맵

1. **Phase 1 (MVP):** 수동 자산 입력 기반 리밸런싱 계산기 (Web 기반). 유틸리티 툴로 포지셔닝하여 비인허가 영역에서 운영.
2. **Phase 2:** 목표 시점별 Glide Path 시각화 및 자동 비중 업데이트 기능. 프리미엄 구독 론칭.
3. **Phase 3:** 증권사 Open API 연동을 통한 실시간 잔고 조회, 세금 한도 자동 체크, Deep-link 주문 연계.
4. **Phase 3+:** 금융 샌드박스 신청 또는 자문업 인가 취득 후 AUM 수수료 모델 전환.
